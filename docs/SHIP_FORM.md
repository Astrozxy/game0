# 舰体造型语言（Form Language）

## 问题

当前舰体主脊是**等径六棱柱**，俯视和侧视都是柱状，缺少"太空战舰"应有的方向感与体量层次。
参考方向需要解决三件事：

1. **方向感**：一眼看出船头在哪
2. **体量层次**：从舰首到舰尾有厚度变化，而不是一根管子
3. **模块落位**：武器/引擎/舰桥要有"长在结构上"的理由

## 选定方向：楔形 / 匕首形（Wedge）

参考：星球大战的歼星舰（Imperial Star Destroyer）、家园的泰坦级、质量效应的联盟无畏舰。

共同特征：

- 俯视是**三角形**：舰首是尖的刃口，越往后越宽
- 侧视是**楔形**：舰首薄，向后逐渐加厚，尾部是巨大引擎组
- 上层建筑集中在**后三分之一**：舰桥、传感器、雷达塔堆在尾部高台上
- 舰首上表面是**大倾角平面**：天然适合布置炮塔（俯视看是一排炮沿中线排列）

这正好和我们的玩法对齐：

| 结构 | 承载硬点 |
|---|---|
| 舰首刃口两侧的斜面 | 舰首主炮 |
| 上层大倾角平面（沿中线） | 前塔 + 背塔 ×3 |
| 两舷外扩的翼面 | 左右舷炮组 |
| 尾部高台 | 舰桥、传感阵 |
| 尾部引擎组（宽扁） | 双/三引擎 |
| 舰体腹面 | 腹部炮塔 |
| 后段厚体 | 弹药库 |

## 几何分解（巡洋舰基准，z 正方向为舰首）

```
俯视：
                  ▲  刃口（尖，宽 0.3）
                 ╱ ╲
                ╱   ╲      ← 大倾角上表面，炮塔沿中线排布
               ╱     ╲
              ╱       ╲
             ╱─────────╲   ← 最宽处（宽 3.4，位于 z ≈ -2）
            ╱  舰桥高台  ╲
           ╱───────────────╲
          ╱  ○   ○   ○      ╲  ← 引擎组（三个喷口）
         ╱───────────────────╲

侧视：
   ───────────────╲                 ← 舰首薄（高 0.3）
                   ╲
                    ╲──────────╲   ← 中部加厚（高 1.0）
                                ╲
                                 ╲─── 尾部最厚（高 1.4）
                                     └ 引擎组
```

## 实施计划

1. **主体**：用 4 棱台（上下两个不同大小的矩形截面）拼出楔形，而不是等径圆柱
2. **舰首刃口**：薄片 + 两侧斜面，取代现在的圆锥撞角
3. **上层大平面**：向后上方倾斜的甲板，炮塔基座沿中线排列
4. **尾部高台**：矩形墩台承载舰桥
5. **引擎组**：宽扁的矩形喷口阵列（3 个），取代外挂短舱
6. **翼面**：保留但改为后掠的三角翼，从最宽处向后展开

## 注意

- 硬点位置必须跟着新结构走，否则模块舱会浮空
- 三个舰级共用同一套形态语言，靠尺寸与细节区分
- 旋转类部件统一用 `Basis` 构造，不要用 `rotation_degrees` 拼复合旋转（已踩过坑）
