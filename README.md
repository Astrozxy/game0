# EMBERFALL · 配船与战斗（可玩原型）

## 怎么运行

双击 `play.bat`。

**打开就直接开打，打完 8 秒自动开始下一场**——不需要任何点击。

想自己配船时，用命令行带 `--builder` 启动：

```powershell
.\tools\godot\Godot_v4.7.2-stable_win64.exe --path game -- --builder
```

## 现在能看到什么

**战斗（默认）**
- 6 对 6 自动交战，玩家不能指挥
- **三种舰级**：巡洋舰（16 硬点）/ 战列舰（20 硬点）/ 航母（14 硬点 + 飞行甲板）
  - 命令行 `--hull=0/1/2` 指定，`--mix` 让敌方用下一种舰级
- 舰体是分层结构：主装甲、收窄舰首、舰尾引擎组、背脊、舰桥塔、传感器桅杆、舷侧灯带、表面设备箱
- **舱室按功能长成不同样子**：
  - 激光炮塔：细长炮管 + **玻璃质感透镜** + 冷却鳍
  - 火炮塔：双联炮管 + **自动装填弹鼓（露出弹头）** + 输弹槽 + 炮闩
  - 近防炮塔：六管加特林 + 弹箱弹链 + 跟踪雷达
  - 引擎舱：**聚变堆造型**——发光主环、约束环、支架、冷却管路、喷口
  - 人员舱：上下铺、餐桌长凳、储物柜、舷窗
  - 弹药库：装甲舱门、警示条、吊装轨道、弹药箱
- **炮塔会转向最近的敌舰**；被打爆后炮塔下垂变黑
- 受损舱室变焦褐色，摧毁后完全熄灯
- 激光画成亮线：蓝 = 我方，红 = 敌方
- 船员（104 人/舰，MultiMesh 单批次）在甲板上跑动，舱室被击穿时四散/被抛出
- 顶部：时间、双方存活舰数、双方存活船员数
- 右下：实时战报（谁打中了谁的哪个舱室）
- 滚轮缩放、点击舰船跟随、空格暂停、可 1× / 2× / 4× 加速

**配船（`--builder`）**
- **顶部选择舰级**：巡洋舰 / 战列舰 / 航母，切换后槽位与默认装配一起变
- 俯视舰体示意图上的真实硬点：舰首炮、背塔、左右舷炮组、腹部炮塔、舰桥、传感阵、引擎、弹药库
- 点击按钮循环切换 8 种舱室：**激光 / 长程炮 / 近防炮** / 弹药库 / 宿舍 / 引擎 / 护盾 / 传感器
- 硬点太近时按钮会自动错开，并用引线连回真实位置
- 右侧实时推算火力、航速、命中、减伤、损管、结构、船员编制
- **战斗手册**：近距 / 中距 / 远距（想在哪打），是否集火残血
- 「出击」进入战斗

### 三种武器

| 武器 | 射程 | 单发 | 射速 | 特点 |
|---|---|---|---|---|
| 激光炮 | 0–35 | 40 | 1.2s | 全能，中近程稳定 |
| 长程炮 | **14**–55 | 92 | 3.0s | 单发最高，**14 以内打不了** |
| 近防炮 | 0–14 | 20 | 0.5s | 射速最快，够不着远的 |

这带来真正的克制：长程舰在接近段白赚输出，但一旦被贴到 14 以内就哑火；近防舰必须活着冲进去。

> **手册的语义**：手册决定"想站在哪打"（影响站位），**不限制开火**。早期版本把手册做成开火硬上限，结果中距手册的舰在 22 外完全无法还击，射程优势直接变成单方面屠戮——已修正。

> **已知问题：集火反而是负收益**。所有舰同时打同一目标会造成大量伤害溢出，实测集火 9 胜 15 负、自由射击 21 胜 3 负。默认已改为自由射击；真正的修法是让舰船之间做目标分配（避免重复攻击同一残血目标），留待后续。

## 舰长与战斗手册

这是本作的核心机制：**玩家不指挥舰船，只写规则**。

- **战斗手册**（玩家定）：规定"允许在什么距离开火"、"是否集火残血"。这是一条**边界**，不是操作。
- **舰长**（玩家不能指定）：每艘船随机拥有一位舰长，性格为 激进 / 稳健 / 谨慎。
  - 激进：把距离压到手册允许的最近处，命中高但挨打也多
  - 谨慎：退到手册允许的最远处，安全但打得慢
  - **关键约束**：舰长的偏好距离被手册夹住，所以他永远在"能开火"的范围内——否则谨慎舰长会退到射程外变成哑巴
- **战果界面**会给出：
  - 双方存活舰数、平均船体、阵亡/幸存船员
  - 双方舰长名单及性格
  - **损失来源**（按舱室类型统计的伤害占比，例如"引擎 39%、护盾 20%、武器 19%"）
  - **头号战果**（本场击杀最多的舰船）


## 已实现的规则

- 激光严格直线；命中在目标自身坐标系里判定（谁朝向入射方向谁挨打）
- 射界：每门武器只能打自己 θ 方向 ±100° 内的目标
- 距离三档（近/中/远）影响命中率与伤害衰减
- 舱室独立生命值；受损降效，归零停转
- 弹药库被击穿会殉爆，按柱坐标相邻度波及周围舱室
- 损管：每艘船有修复预算，自动修最要紧的舱室
- 船员：每舱室有编制；挨打会死人；死人会降低命中与损管速度
- 集火：舰长先选主目标（同分随机），再让各武器打它
- 每艘船一条独立随机流（避免"谁先取数"变成系统性优势）

## 已知问题

- **公平性仍有残留偏差**：双方同配置时，我方胜率约 35–40%。已从最初的 13% 提升到 35–40%，但还没归零。
- 船员数量（每舰 12 个可见小人）是表现层配额，和逻辑层编制（200+ 人）不是一一对应。
- 无存档、无录像回放；战斗画面本身就是"回放"。

## 目录

```
game/                  Godot 工程
  main.tscn            入口场景
  main.gd              流程：战斗 → 战果 → 自动下一场（或 --builder 配船）
  sim/model.gd         数据模型（舱室、船员、舰船、损管）
  sim/battle_sim.gd    战斗推进（纯逻辑，不含渲染）
  ui/ship_builder.gd   配船界面
  battle/battle_view.gd 战斗表现（舰体、船员、失压、镜头、HUD）
  test/                无头测试脚本
tools/godot/           Godot 4.7.2 引擎（不进 git）
docs/                  设计文档
```
