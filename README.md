# EMBERFALL · 配船与战斗（可玩原型）

## 怎么运行

双击 `play.bat`。

**打开就直接开打，打完 8 秒自动开始下一场**——不需要任何点击。

想自己配船时，用命令行带 `--builder` 启动：

```powershell
.\tools\godot\Godot_v4.7.2-stable_win64.exe --path game -- --builder
```

## 现在能看到什么

**战斗（默认）**
- 6 对 6 自动交战，玩家不能指挥
- 舰体由「舰体 + 10 个舱室方块」组成：颜色 = 类型，变橙 = 受损，变黑 = 停转
- 激光画成亮线：蓝 = 我方，红 = 敌方
- 船员（白色小人）在舱室之间跑动：去修理受损舱室、在炮位待命
- 舱室被击穿时会失压，**船员被抛到太空里飘走**
- 顶部：时间、双方存活舰数、双方存活船员数
- 右下：实时战报（谁打中了谁的哪个舱室）
- 滚轮缩放、点击舰船跟随、空格暂停、可 1× / 2× / 4× 加速

**配船（`--builder`）**
- 中央动力仓，10 个固定槽位：外圈 5 个前部（h=+1），内圈 5 个后部（h=-1）
- 点击槽位切换舱室：武器 / 弹药库 / 宿舍 / 引擎 / 护盾 / 传感器
- 右侧实时推算火力、航速、命中、减伤、损管、结构、船员编制
- **战斗手册**：允许近距 / 中距 / 远距开火，是否集火残血
- 「出击」进入战斗

## 舰长与战斗手册

这是本作的核心机制：**玩家不指挥舰船，只写规则**。

- **战斗手册**（玩家定）：规定"允许在什么距离开火"、"是否集火残血"。这是一条**边界**，不是操作。
- **舰长**（玩家不能指定）：每艘船随机拥有一位舰长，性格为 激进 / 稳健 / 谨慎。
  - 激进：把距离压到手册允许的最近处，命中高但挨打也多
  - 谨慎：退到手册允许的最远处，安全但打得慢
  - **关键约束**：舰长的偏好距离被手册夹住，所以他永远在"能开火"的范围内——否则谨慎舰长会退到射程外变成哑巴
- **战果界面**会给出：
  - 双方存活舰数、平均船体、阵亡/幸存船员
  - 双方舰长名单及性格
  - **损失来源**（按舱室类型统计的伤害占比，例如"引擎 39%、护盾 20%、武器 19%"）
  - **头号战果**（本场击杀最多的舰船）


## 已实现的规则

- 激光严格直线；命中在目标自身坐标系里判定（谁朝向入射方向谁挨打）
- 射界：每门武器只能打自己 θ 方向 ±100° 内的目标
- 距离三档（近/中/远）影响命中率与伤害衰减
- 舱室独立生命值；受损降效，归零停转
- 弹药库被击穿会殉爆，按柱坐标相邻度波及周围舱室
- 损管：每艘船有修复预算，自动修最要紧的舱室
- 船员：每舱室有编制；挨打会死人；死人会降低命中与损管速度
- 集火：舰长先选主目标（同分随机），再让各武器打它
- 每艘船一条独立随机流（避免"谁先取数"变成系统性优势）

## 已知问题

- **公平性仍有残留偏差**：双方同配置时，我方胜率约 35–40%。已从最初的 13% 提升到 35–40%，但还没归零。
- 船员数量（每舰 12 个可见小人）是表现层配额，和逻辑层编制（200+ 人）不是一一对应。
- 无存档、无录像回放；战斗画面本身就是"回放"。

## 目录

```
game/                  Godot 工程
  main.tscn            入口场景
  main.gd              流程：战斗 → 战果 → 自动下一场（或 --builder 配船）
  sim/model.gd         数据模型（舱室、船员、舰船、损管）
  sim/battle_sim.gd    战斗推进（纯逻辑，不含渲染）
  ui/ship_builder.gd   配船界面
  battle/battle_view.gd 战斗表现（舰体、船员、失压、镜头、HUD）
  test/                无头测试脚本
tools/godot/           Godot 4.7.2 引擎（不进 git）
docs/                  设计文档
```
