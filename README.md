# EMBERFALL · 配船与战斗（第一版可玩原型）

## 怎么玩

双击 `play.bat`（或右键 `play.ps1` → 用 PowerShell 运行）。

## 这一版有什么

**配船界面**
- 中央是动力仓，周围 10 个固定槽位：外圈 5 个是前部（h=+1），内圈 5 个是后部（h=-1）
- 点击槽位循环切换舱室类型：武器舱 / 弹药库 / 人员宿舍 / 引擎 / 护盾发生器 / 传感器
- 右侧实时显示推算性能：火力、航速、命中、减伤、损管、总结构
- 「出击」进入战斗；「重置默认」回到初始装配

**战斗**
- 6 对 6，双方使用同一套规则自动交战，你只能看
- 顶部：时间、双方存活数
- 右下：实时战报（谁打中了谁的哪个舱室）
- 每艘船由「舰体 + 10 个舱室方块」组成：
  - 舱室颜色 = 类型；变橙 = 受损；变暗 = 停转
  - 激光画成亮线
- 可暂停、可 1× / 2× / 4× 加速
- 打完弹出战果：存活数、平均船体、各类型舱室损失

## 已经实现的规则

- 激光严格直线：从武器舱出发，在目标自身坐标系里判定「谁朝向入射方向谁挨打」
- 射界：每门武器只能打自己 θ 方向 ±100° 内的目标（所以船怎么转有影响）
- 距离三档（近/中/远）影响命中率与伤害衰减
- 舱室独立生命值；受损降效，归零停转
- 弹药库被击穿会殉爆，按柱坐标相邻度波及周围舱室
- 损管：每艘船有修复预算，战斗中自动修最要紧的舱室
- 集火：舰长先选主目标，再让各武器打它

## 目录

```
game/             Godot 工程
  main.tscn       入口场景
  main.gd         流程：配船 → 战斗 → 战果
  sim/model.gd    数据模型（舱室、舰船、损管）
  sim/battle_sim.gd  战斗推进（纯逻辑，不含渲染）
  ui/ship_builder.gd 配船界面
  battle/battle_view.gd 战斗画面与 HUD

tools/godot/      Godot 4.7.2 引擎本体
```
